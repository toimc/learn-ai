### Task 6【review】独立审查

- 只给 spec 路径 + worktree diff，不共享实现过程上下文

- 输出问题清单，orchestrator 决定修复

### Task 7【orchestrator】Vercel 项目创建 + 部署

```bash
export VERCEL_TOKEN='<'7 天临时 token，不入库>'
npx vercel project add ai-chat-ui --token "$VERCEL_TOKEN"   # 已存在则跳过
cd .claude/worktrees/deploy-vercel
npx vercel link -p ai-chat-ui -y --token "$VERCEL_TOKEN"
npx vercel deploy --prod -y --token "$VERCEL_TOKEN"
```

- 失败排查顺序：构建日志 → pnpm/workspace 解析 → 函数打包（monorepo 跨目录 import）
- 备选：若 CLI project add 不支持当前版本，用 `vercel link --yes` 默认建项目后改名

## 风险与回退

| 风险 | 缓解 |
|---|---|
| Vercel 构建 monorepo 失败 | 复用 e2e CI 已验证的 install/build 序列；Root Directory 保持仓库根 |
| api 函数跨目录 import 打包失败 | 改为在 packages/mock-server 内建产物再引用；或内联 app 入口 |
| SSE 被缓冲不流式 | 检查 Fluid Compute 设置；显式 `x-accel-buffering: no` 类响应头 |
| token 过期（7 天） | 部署动作集中在本次会话完成；后续由用户在 dashboard 重设 |
