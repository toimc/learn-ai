# 基础表单原语组件 — 需求规格

> 日期：2026-08-22 · 状态：用户指令直接开发（「按钮/input/select/radio 参考原子 CSS 设计好看样式，基础组件同样需要」）
> 视觉基准：shadcn/Tailwind 设计语言（subtle border、focus ring、统一控件高度、150ms transition、暗色自动适配）。
> **实现红线：只用本项目 token 体系（--ai-chat-*），不引入 Tailwind/UnoCSS 等原子 CSS 框架**（CLAUDE.md 样式规范）。

## 1. 目标

`@toimc/vue` 新增/升级四个公共基础组件，视觉达到原子 CSS 体系设计的现代水准，供宿主与库内组件（ProviderSettingsDialog 等）复用。

## 2. 组件契约

### 2.1 tokens 先行（`packages/vue/src/styles/tokens.css`）
在 tokens 层新增控件尺寸与状态令牌（明暗两处都要）：
- `--ai-chat-control-height-sm: 32px` / `--ai-chat-control-height-md: 36px`
- `--ai-chat-control-ring: <accent 低透明度 3px 阴影>`（focus ring，用 color-mix 或既有 accent-dim 令牌组合）
- 复用既有：`--ai-chat-radius-md`、`--ai-chat-color-input-*`、`--ai-chat-color-accent-*`、neutral 色阶

### 2.2 `Input`（`packages/vue/src/shared/Input.vue`）
- Props：`modelValue`（v-model）、`type?: 'text'|'password'`（默认 text）、`placeholder?`、`disabled?`、`invalid?`（aria-invalid + error 边框）、`size?: 'sm'|'md'`（默认 md）、`autocomplete?` 透传
- 事件：`update:modelValue`；`blur` 透传（弹层 touched 逻辑需要）
- 视觉：input-bg、1px input-border、radius-md、hover 边框加深、focus 边框 accent + 3px ring、placeholder muted、disabled 降透明度、transition 150ms

### 2.3 `Select`（`packages/vue/src/shared/Select.vue`）
- Props：`modelValue`（v-model）、`disabled?`、`invalid?`、`size?`；`<option>` 走默认插槽透传
- 事件：`update:modelValue`
- 视觉：与 Input 同族（appearance-none + 右侧 chevron 用 mask/内联 SVG，暗色适配），focus ring 一致

### 2.4 `Radio`（`packages/vue/src/shared/Radio.vue`）
- Props：`modelValue`（v-model，选中的 value）、`value: string`、`label?: string`、`disabled?`
- 事件：`update:modelValue`（选中时 emit 自身 value）
- 视觉：原生 input 隐藏（保留可访问性）+ 自绘圆环（border→accent，选中实心 accent 圆点 + ring），label 水平排列可点击；`name` 由宿主分组

### 2.5 `Button` 视觉升级（`packages/vue/src/shared/Button.vue`）
- **Props/Events API 不变**（type: primary/secondary/danger，size: small/medium/large）
- 升级点：去掉硬编码 hex fallback 全换 token；`:focus-visible` ring；active 轻微下沉（transform/亮度）；高度对齐 control-height 体系；transition 统一 150ms；`prefers-reduced-motion` 尊重

### 2.6 导出与一致性
- 四组件全部从 `@toimc/vue` 主入口导出；样式遵守 style-isolation.md（`.ai-chat-` 前缀、`@layer ai-chat-components`、无 `!important`、无硬编码色值）

## 3. ProviderSettingsDialog 重构

- 表单控件换用 Input/Select/Radio/Button：类型选择 → Radio×2（fieldset/legend 保留）、名称/模型 → Input、apiKey → Input(type=password)、baseURL → Input + 预设按钮（Button size=small type=secondary）
- **行为零变化**：既有 15+5 条测试（含盲测）必须不改断言全绿；只换实现不换契约

## 4. 文档

- `packages/docs/components/` 新增 button.md / input.md / select.md / radio.md 四页（Props/Events/示例，风格对齐既有组件页）
- `.vitepress/config.ts` 侧栏新增「基础组件」分组收录四页

## 5. 测试

- 每组件三场景（正常渲染与 v-model 双向 / disabled 与 invalid 状态类与 aria / 边界：空值、slot 内容），红灯先行，预期值字面量
- Button 存量测试不动（API 未变），新增 focus-visible/active 类断言用例
- 重构后弹层既有测试不改断言全绿

## 6. 不做

- 不做 Checkbox/Switch/Textarea（未要求，弹层不需要）
- 不做 Select 虚拟列表/自定义 listbox（原生 option 足够）
- 不引入任何原子 CSS 框架
