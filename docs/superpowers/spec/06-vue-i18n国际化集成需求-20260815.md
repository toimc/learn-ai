# vue-i18n 国际化集成需求规格

> 日期：2026-08-15
> 状态：已获用户批准的设计，待实施
> 范围：packages/vue + packages/markdown + packages/playground（VitePress 文档站多语言为后续独立阶段，不在本 spec 内）

## 1. 背景与目标

组件库当前 i18n 完全从零：无 vue-i18n 依赖、无字典，约 12 处 UI 文本硬编码散布在 `packages/vue`（中文 7 处 + 英文 4 处）与 `packages/markdown`（CodeBlock 复制 title 1 处），playground 演示页另有大量硬编码中文文案。

目标：

1. 以 vue-i18n v11 为引擎集成国际化，中英双语（zh-CN / en-US）优先
2. 翻译文件按官方推荐结构组织（`locales/` 目录 + 按语言分文件），TS 格式 + 类型约束，方便后续更新与扩展
3. 新增语言切换基础组件 `LanguageToggle`（下拉选择器形态）
4. playground 接入作为实际验证载体
5. 沉淀项目级 i18n skill，使后续新组件开发自动遵循 i18n 规范

## 2. 关键决策（已确认）

| 决策点 | 结论 |
|---|---|
| vue-i18n 定位 | 深度集成：`vue-i18n@11` 作为 `@ai-chat/vue` 的 dependency，非 peer/optional |
| 实例组织 | **模块级单例**：库内 `createI18n({ legacy: false })` 实例并导出，组件直接使用 composer（`aiChatI18n.global`），不要求宿主 `app.use`；宿主零配置即得中英切换 |
| 字典组织 | 每语言单 TS 文件 + 组件命名空间；`zh-CN.ts` 为 source of truth，`en-US.ts` `satisfies MessageSchema` |
| 覆盖范围 | 库（vue/markdown）+ playground；docs 站点多语言后续独立阶段 |
| props 与字典关系 | **props 优先、i18n 兜底**：文本 props 默认值改 `undefined`，未传时回退 `t()`；完全向后兼容 |
| LanguageToggle 形态 | 下拉选择器（触发按钮 + Teleport 弹层列表） |

## 3. 架构设计

### 3.1 目录结构

```
packages/vue/src/locales/
├── zh-CN.ts      # 中文字典（source of truth，as const）
├── en-US.ts      # 英文字典（satisfies MessageSchema）
└── index.ts      # aiChatI18n 单例、MessageSchema 类型、setAiChatLocale()、LocaleOption 类型

packages/playground/src/locales/
├── zh-CN.ts      # 演示页文案（pg 命名空间）
└── en-US.ts
```

### 3.2 i18n 实例

```ts
// packages/vue/src/locales/index.ts（示意）
export const aiChatI18n = createI18n({
  legacy: false,
  locale: 'zh-CN',
  fallbackLocale: 'zh-CN',
  messages: { 'zh-CN': zhCN, 'en-US': enUS },
  missingWarn: import.meta.env.DEV,   // dev 缺 key 告警
  fallbackWarn: import.meta.env.DEV,
})
export type MessageSchema = typeof zhCN
export type AiChatLocale = 'zh-CN' | 'en-US'   // 内置语言；宿主可 setLocaleMessage 扩展更多
```

- 组件内 `const { t } = aiChatI18n.global`（composer 解构安全，与官方 `const { t } = useI18n()` 同理；模板中调用自动追踪 locale 响应）
- 宿主可 `aiChatI18n.global.setLocaleMessage(locale, messages)` 注入自定义语言/覆盖文案
- 与宿主自有的 vue-i18n 实例天然隔离（各自实例）

### 3.3 语言切换与持久化

```ts
setAiChatLocale(locale: string, opts?: { persist?: boolean }): void   // string 而非联合类型，兼容宿主扩展语言
getInitialLocale(): AiChatLocale   // localStorage > navigator.language 匹配 > 'zh-CN'
```

- 持久化 key：`ai-chat-locale`（localStorage）
- 同步 `document.documentElement.lang`（官方 `setI18nLanguage` 做法）
- `document` / `localStorage` 全部 `typeof window` guard（SSR 安全）

### 3.4 markdown 包

`@ai-chat/markdown` 已依赖 `@ai-chat/vue`，复用同一 `aiChatI18n` 实例；CodeBlock 文案走 `markdown` 命名空间（`markdown.copy` / `markdown.copied`），不单独建字典设施。

## 4. 字典设计

命名空间 = 组件域，key 用 camelCase：

| namespace | 覆盖内容 | 来源组件 |
|---|---|---|
| `shared` | 关闭、复制 | Toast aria-label 等公共文案 |
| `promptInput` | placeholder、免责声明 footer | PromptInput.vue |
| `conversation` | 空态标题/描述 | ConversationEmpty.vue |
| `message` | 你 / AI Chat UI（角色名） | Message.vue slot 默认 |
| `toolCall` | 参数/结果/错误 | ToolCallInput.vue、ToolCallOutput.vue |
| `attachments` | 暂无附件 | AttachmentEmpty.vue |
| `comparison` | 回复 A/回复 B/喜欢这个 | ComparisonMessage.vue |
| `markdown` | 复制代码/已复制 | CodeBlock.vue |
| `inputArea` | 旧版 placeholder/Send/Stop | InputArea.vue（旧版组件一并接入） |
| `pg.*` | playground 演示页文案（playground 包自带字典合并进实例） | PlaygroundDemo.vue 等 |

类型约束链：`zh-CN.ts` `as const` → `MessageSchema = typeof zhCN` → `en-US.ts` `satisfies MessageSchema`。**缺 key / 键名写错 = 编译期报错**（vue-i18n 官方 TypeScript 推荐用法）。

## 5. 组件接入模式（props 优先、i18n 兜底）

统一改造模式：

```ts
// 文本 props 默认值改 undefined，computed 回退 t()
const displayTitle = computed(() => props.title ?? t('conversation.emptyTitle'))
```

- slot 默认内容直接写 `{{ t('...') }}`
- 需改造文件（约 9 个）：ConversationEmpty、AttachmentEmpty、Message、PromptInput、Toast（aria-label）、ComparisonMessage、ToolCallInput、ToolCallOutput、InputArea（旧版）
- **零 breaking**：现有宿主代码与现有 props 用法全部不变

## 6. LanguageToggle 组件

位置：`packages/vue/src/shared/LanguageToggle.vue`，从 `packages/vue/src/index.ts` 导出。

- **交互**：触发器 `🌐 {当前语言名} ▾` → 点击展开下拉列表 → ✓ 标记当前语言 → 点击选项切换；点击组件外部 / Esc 关闭
- **弹层**：Teleport 到 body，fixed 定位（`getBoundingClientRect` 计算位置，默认在触发器下方，视口空间不足时翻转到上方）；`tokens.css` 新增 `--ai-chat-z-popup` 令牌（遵守样式隔离规则第 6 条，禁止裸写 z-index）
- **无障碍**：`role="listbox"` / `role="option"`、触发器 `aria-expanded` / `aria-haspopup="listbox"`
- **Props**：
  - `locales?: LocaleOption[]`，默认 `[{ value: 'zh-CN', label: '简体中文' }, { value: 'en-US', label: 'English' }]`
  - `modelValue?: string`（可控用法；未传时直接驱动 `aiChatI18n` 并维持内部状态）
- **Events**：`update:modelValue`、`change(locale: string)`
- **样式**：入 `@layer ai-chat-components`，类名前缀 `ai-chat-lang-toggle`（BEM），尺寸风格对齐 `PromptInputSubmit` / playground `pg-btn-icon`，颜色全部走 `--ai-chat-*` 变量

## 7. Playground 接入

- 工具栏「切换主题」按钮旁放置 `LanguageToggle`（复用方案一零配置特性，无需 app.use）
- playground UI 文案接入字典：按钮 title（重命名/删除/收起侧边栏/切换布局）、欢迎语、空态、搜索 placeholder、confirm 文案、工具按钮 title、输入提示等
- **不接**：mock 对话数据（mock-messages / mock-comparison，属示例数据非 UI 文案）；`tokens-meta.ts` / `presets.ts` 主题中文 label（主题配置器元数据，列入后续优化项）
- playground 字典通过 `aiChatI18n.global.setLocaleMessage` 合并进同一实例（`pg` 命名空间），一个开关同时切换库文案与演示页文案

## 8. i18n Skill

位置：`.claude/skills/i18n/SKILL.md`（项目级），frontmatter 对齐现有 skill（name + description）。

description 覆盖触发场景：新建/修改组件、新增 UI 文案、新增语言。内容五条纪律：

1. UI 文案禁止硬编码，按组件域 namespace 进字典
2. `zh-CN.ts` 与 `en-US.ts` 必须同次提交同时更新，`en-US.ts` 保持 `satisfies MessageSchema`
3. key 用 camelCase，namespace = 组件域（新组件新建 namespace）
4. 文本 props 用「props 优先、`t()` 兜底」模式，不写死默认文案
5. 完成后同步 VitePress 组件文档（文档同步门禁）

另在项目 `CLAUDE.md` 增加一行引用（确保新组件任务自动触发该 skill）。

## 9. 测试

| 层 | 用例 |
|---|---|
| 字典 | zh-CN / en-US key 树深度一致（递归对比）；`t()` 抽查中英文输出 |
| 组件改造 | 未传文本 props → 渲染字典文案；传 props → props 优先；`setAiChatLocale('en-US')` 后文案响应式更新 |
| LanguageToggle | 默认渲染当前 locale；展开列表；选择后 emit `change` / `update:modelValue` 且 `aiChatI18n` locale 变更；点击外部关闭；Esc 关闭 |
| markdown | CodeBlock 复制 title 断言更新为字典文案 |

## 10. 错误处理与边界

- **缺 key**：dev 环境 vue-i18n missingWarn 告警，运行时 fallback 到 `zh-CN`
- **SSR（VitePress）**：模块级单例 locale 跨请求共享——静态文档站可接受（`useTheme` 同先例）；所有 DOM/localStorage 访问有 guard
- **宿主已有 vue-i18n**：实例隔离互不干扰；宿主可注入更多语言

## 11. 文档同步（门禁）

- VitePress 新增 i18n 指南页（快速开始 / 字典组织 / setAiChatLocale / 宿主注入自定义语言）
- VitePress 组件文档新增 LanguageToggle 页（Props / Events / 用法示例）

## 12. 非目标（明确不做）

- VitePress 文档站整体多语言（en 目录 + nav/sidebar 双语）
- 第三语言及更多语言（架构已留扩展点：`setLocaleMessage` + `LanguageToggle` 的 `locales` prop）
- mock 数据、主题配置器元数据（tokens-meta / presets）的国际化
- vue-i18n 的 SFC `<i18n>` 自定义块（与单文件字典方案冲突，不采用）
