# 样式隔离与样式 Rules 需求规格

> 日期:2026-08-15 | 状态:已批准
> 关联:`docs/superpowers/spec/02-主题系统与主题配置器-20260813.md`(本 spec 增补其 ADR,不推翻其决策)

## 1. 背景与问题

样式审计发现,组件库对宿主应用存在三类污染:

| # | 问题 | 位置 | 严重度 |
|---|------|------|--------|
| P1 | 97 个 `--ai-chat-*` 变量 + 全局 `*` box-sizing reset 定义在 `:root`,随 `@ai-chat/vue` 入口无条件注入,无级联防护 | `packages/vue/src/styles/tokens.css:12-181` | 高 |
| P2 | `useTheme` 模块加载即把 `data-theme` 写到宿主 `<html>` 并写 `localStorage`,与宿主自有主题系统冲突 | `packages/vue/src/composables/useTheme.ts:50-60` | 高 |
| P3 | `katex.min.css`(含全局 `@font-face` 字体下载)随 markdown 包模块级强制注入,无法 opt-out | `packages/markdown/src/composables/useMarkdownIt.ts:6` | 中 |

已有良好基础:全部类选择器严格 `.ai-chat-` 前缀、零裸元素/body/html 顶级规则、零 `!important`、Mermaid 走 sandbox iframe 天然隔离。缺的是**硬防护**。

## 2. 已批准决策

1. **保持 `:root` 令牌**(遵循 spec 02 原决策),新增 `@layer` 级联防护——不做组件根作用域迁移,不引入 Shadow DOM。
2. **useTheme 增加挂载目标选项**:`target: 'html' | 'component'`(默认 `'html'` 向后兼容)、`persist: boolean`(默认 `true`)。
3. **KaTeX CSS 拆可选导入**:移除模块级注入,改为包的子路径导出 `@ai-chat/markdown/katex.css`。
4. **Rules 沉淀到项目级** `.claude/rules/style-isolation.md`。

## 3. 功能需求

### FR-1 @layer 分层

- `tokens.css` 顶部声明层顺序:`@layer ai-chat-base, ai-chat-tokens, ai-chat-components, ai-chat-animations;`
- `tokens.css` 变量块进 `@layer ai-chat-tokens`;动画文件进 `@layer ai-chat-animations`
- packages/vue 全部非 scoped `<style>` 块、packages/markdown 的非 scoped 块(CodeBlock/LatexBlock/MermaidBlock)包进 `@layer ai-chat.components { ... }`
- 已 scoped 的块(MarkdownRenderer 等)不强制包层——scoped 带 data-v 属性天然不泄漏,规则中说明
- 收益:宿主未分层样式天然覆盖库样式,无需 `!important`

### FR-2 全局 reset 收敛

`*` box-sizing 改为:

```css
@layer ai-chat-base {
  .ai-chat-window, .ai-chat-window *, .ai-chat-window *::before, .ai-chat-window *::after {
    box-sizing: border-box;
  }
}
```

`@layer` 解决优先级污染,选择域收窄解决命中范围污染,两者缺一不可。

### FR-3 useTheme 挂载目标

```ts
useTheme(options?: { target?: 'html' | 'component'; persist?: boolean })
// 默认 target: 'html'、persist: true,现有调用零改动
```

- `target: 'component'`:`data-theme` 写到 `.ai-chat-window` 根元素,不碰宿主 `<html>`
- 兼容性依据:tokens.css 的 `[data-theme='dark']` 是属性选择器,匹配任意携带该属性的元素,挂组件根时暗色变量只作用于组件子树
- `persist: false` 关闭 localStorage 写入

### FR-4 KaTeX 可选导入

- 从 `useMarkdownIt.ts` 移除 `import 'katex/dist/katex.min.css'`
- `packages/markdown/package.json` exports 增加 `'./katex.css'` 子路径(构建产物)
- playground 与 docs 站补 `import '@ai-chat/markdown/katex.css'` 保持现有体验
- 文档写明:渲染公式需手动引入该 CSS;不用公式的宿主省 ~25KB CSS + 全局数学字体下载

### FR-5 项目级 Rules

新建 `.claude/rules/style-isolation.md`,板块:

1. **命名纪律**:类选择器必须 `.ai-chat-` 前缀
2. **@layer 铁律**:所有库样式必须进 `ai-chat-*` 层;严禁未分层规则;新层需在 tokens.css 声明顺序
3. **禁入区**:`:root`/`*`/裸 `body`/`html`/裸元素选择器只允许出现在 tokens.css 既定位置;禁止 `!important`;禁止组件内写 `@font-face`
4. **第三方 CSS**:必须走可选子路径导出,禁止模块级隐式注入
5. **主题联动**:颜色必须走 `--ai-chat-*` 变量;`data-theme` 只能经 `useTheme` 的 target 写入;组件不得直接依赖宿主 `<html>` 属性做样式判断
6. **z-index**:组件内局部小值(≤10)自由使用;Teleport 弹层需先定 z-index 令牌
7. **新增样式检查清单**:前缀/层/禁入区/主题变量/作用域五项自查

## 6. 验收标准

1. 引入 `@ai-chat/vue` 后,宿主一行未分层 CSS(如 `.my-btn { color: red }`)即可覆盖组件库任意对应样式,无需 `!important`
2. 宿主文档中除 `.ai-chat-window` 子树外,无任何元素被组件库规则命中(box-sizing 等)
3. `useTheme({ target: 'component', persist: false })` 运行时,宿主 `<html>` 无 `data-theme` 写入、无 localStorage 写入,组件内明暗切换正常
4. 不引入 `@ai-chat/markdown/katex.css` 时无 KaTeX 样式与字体下载;引入后公式渲染与现状一致
5. playground/docs 现有明暗切换、公式渲染、Mermaid 图表不回退
6. `.claude/rules/style-isolation.md` 存在且内容覆盖 FR-5 全部板块
