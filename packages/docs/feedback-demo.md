本页演示对话入口与消息级反馈闭环：[`Welcome`](/components/welcome) +
[`Prompts`](/components/prompts) 选提示词填入输入框（输入 `/` 或 `@` 体验
[`PromptInputSuggestion`](/components/prompt-input-suggestion) 内联建议）；
消息侧为操作四件（[Copy](/components/message-actions) 真实复制 / Retry 追加分支 /
Edit 原位编辑 / [Feedback](/components/message-feedback) 点赞点踩评论）与
[`BranchPicker`](/components/branch-picker) 三分支翻页，事件日志实时展示宿主侧上报。
