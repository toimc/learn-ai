本页演示 RAG 回答的完整引用链路：[`ThinkingChain`](/components/thinking-chain)
多步骤检索过程（含 active / complete / error 各态）、正文角标
[`InlineCitation`](/components/inline-citation)（hover 预览引用片段、多来源轮播）、
回答末尾 [`Sources`](/components/sources) 折叠来源列表，以及
[`ToolConfirmation`](/components/tool-confirmation) 的允许 / 拒绝审批流转。

协议与宿主侧接入配方见 [引用与来源](/guide/citations)；完整聊天场景（消息流、多会话）见
[Playground](/playground)。
